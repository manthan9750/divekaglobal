# Divekaa Global

Premium flavored-jaggery (gud) cubes brand e-commerce platform. 
Built by Team Pika Growth.

## Tech Stack
- Next.js 14.2 (App Router)
- Tailwind CSS 3.4
- TypeScript
- Vercel

## Local Development
1. Copy `.env.example` to `.env.local` and add your keys.
2. Run `npm install`
3. Run `npm run dev`
